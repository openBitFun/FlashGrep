# 大增量合并策略复测

同一份 50,000 文件数据，普通目录和 Git 仓分别运行三轮。旧 flashgrep 与 tgrep 的数据来自完整基线，新 flashgrep 使用独立副本和索引，保留相同变更序列及查询。未重新运行未修改的 tgrep；其数据不是与新版同步交错测量的。

更新耗时取三轮中位数，从本档第一次写文件到结果完整且状态就绪；RSS 峰值取三轮最大值。查询 p50 汇总三轮各 20 次稳定查询。基线正确不表示所有后台校准空闲，首批更新可能与启动工作重叠；两种工具的就绪条件不同，详见各自报告。所有指标为 TCP RPC 端到端观测，数据不单独证明某种存储介质的因果收益。
